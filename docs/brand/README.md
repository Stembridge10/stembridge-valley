# Junimo Hollow brand

Logo: leaf arch with a gold star (owner-approved, variant A). Drawn by GPT image generation from
our brief, then recolored pixel-exact with `recolor.py` from `source-round1-logo3.png`.
Launcher icon and header art are built by `make_assets.py` into `src/Launcher/Assets/`.

Palette "Starlit Hollow":
- Night `#191728`: window background
- Dusk `#28223E`: header band, title bar, main button text
- Ivory `#F4ECDD`: main text
- Lilac `#B9AECB`: muted text, borders
- Lavender `#B8A0DE`: main button, logo arch
- Gold `#E4BE66`: accent, star
